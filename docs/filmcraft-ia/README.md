# FilmCraft IA

FilmCraft IA is a personal, non-commercial tool that runs on its owner's own computer. It turns long
videos and live streams into short vertical clips (subtitles, framing, titles) with FilmCraft, and
publishes those clips to the owner's own TikTok and YouTube accounts.

It is not a public service: only the owner of this repository uses it, with their own accounts.
